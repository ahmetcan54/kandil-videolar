# kandil-videolar

[@kandil.kissalar](https://www.instagram.com/kandil.kissalar/) Reels dosyaları. Kaynaklı kıssa videoları.

- Videolar **release** olarak durur; Instagram `video_url` ile buradan indirir.
- `kuyruk.json`: yayın sırası. Gece üretimi (Ahmet'in bilgisayarı) ekler, `.github/workflows/yayin.yml`
  her gün 19:00 (TR) sıradakini Instagram'a yayınlar ve sonucu buraya yazar.
